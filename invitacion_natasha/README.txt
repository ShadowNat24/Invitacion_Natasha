INVITACIÓN NATASHA - V1

Esta versión contiene:
- Portada inspirada en el diseño que hiciste en Canva.
- El gato del meme como sello del sobre.
- Botón interactivo: tocar el gato.
- Animación de apertura.
- Segunda pantalla de la invitación.
- Botón de confirmación como placeholder.

IMPORTANTE:
Todavía NO hay base de datos ni formulario PHP/MySQL.
Eso lo hacemos en el siguiente paso.

PARA PROBAR CON XAMPP:
1. Copiá la carpeta "invitacion_natasha" dentro de htdocs.
2. Iniciá Apache en XAMPP.
3. Abrí:
   http://localhost/invitacion_natasha/

Para cambiar el texto, editá index.php.
Para cambiar colores/diseño, editá assets/style.css.
Para cambiar la animación, editá assets/script.js.
